# 测试计划

> 状态：1.8-beta。自动化测试在仓库的 `tests/` 里（`python3 tests/run.py`），结果见 `工作记录.md` 第 6 节。
> 下面是需要在真机、用真实照片做的测试，按顺序进行。第一轮里「星级」的检查项从 1.8-beta 起改为「分数」（见第六轮）。

## 第一轮：Sony ARW 跑通（`~/Desktop/TestFIle`，120 组 ARW＋JPG）
1. 照片筛选：演练模式跑一次，看评分是否合理（TestFIle 里不应多出 `.xmp`）。
2. 照片筛选：关掉演练，勾「整理输出」（复制、两层、重命名）跑一次；核对 `整理输出/保留|淘汰/JPEG|RAW/星级_ILCE-1M2_原名`。
3. 报告里：一张改 ✕、一张改 5★、删一张；输出文件夹应跟着变。
4. 再跑一次：输出不重复，手动改的星级还在。
5. 把 `整理输出/保留/RAW` 导入 Lightroom / Capture One，看星级和色标（需要本人操作）。
6. 移动模式：用 `~/Desktop/TestFIle_移动测试`（10 组）。
7. 照片编辑：打开一张 ARW，顶部显示「RAW」；四种自动方案各试一次；四支镜头的暗角各看一下；导出 JPEG 和 16 位 TIFF。

## 第二轮：环境与打包
1. macOS：`安装环境.command --check`、`--recreate` 各跑一次；`启动筛选` / `启动编辑` 能直接打开。
2. Windows 实机：解压测试包，`安装环境.bat` 全新安装（含 winget 安装 Python），再启动两个程序。
3. 镜像切换（`--mirror tuna`）与离线安装（`--download` → `--wheels`）。

## 第三轮：LUT
1. 内置库显示两个分组（Fujifilm GFX 胶片模拟 20、Leica Look 19），全部标为 sRGB，无警告。
2. 抽查 6 个 LUT 的效果：Leica Look BLE / PURE / BW HC，GFX50S CLASSIC CHROME / ASTIA / ACROS。
3. 添加 LUT：选多个 `.cube`（含一个坏文件），好的进「我的 LUT」，坏的给出原因；重名自动加 (2)；移除后列表更新、正在用的 LUT 被取消。
4. 旧编辑记录（改名前保存的）能自动对应到新 LUT。

## 第四轮：多语言与新模型（1.6）
1. 右上角切换 简体中文／English／日本語：两个程序同步切换；报告页、运行日志、错误提示跟着变；Windows 上「资源管理器／回收站」的说法正确。
2. 三种语言下检查排版：按钮、标签没有截断或竖排；日文字体正常（不是中文字形）。
3. 用英文界面整理一次输出：文件夹名为 `Keep`／`Rejected`；之后在报告里改星级，照片换到正确的文件夹。
4. 载入 1.5 生成的旧结果：问题标记、题材按当前语言显示。
5. DeepSeek 真实调用（`deepseek-flash`）：评语语言正确、费用正常（会产生少量费用，需本人确认后再测）。
6. 自定义接口：通义千问或本地 Ollama 视觉模型各试一次。

## 第五轮：一体窗口与 Mac 应用（1.7）
1. 双击「启动筛选.command」：浏览器里只有一个窗口；页头「照片筛选｜照片编辑」和 ⌘1／⌘2 切换，两边状态都保留。再双击「启动编辑.command」只会打开现有窗口。
2. 筛选完成后在报告里点「编辑」：直接切到编辑并打开那张照片。
3. 双击「打包Mac应用.command」：打包成功，自检全部 ✓，生成 dist/mac/照片工具.app 和 zip。
4. 打开「照片工具.app」：没有终端窗口；完整走一遍筛选、复核、编辑、导出；添加 LUT 的文件选择框能弹出；「在浏览器中打开报告」用默认浏览器打开。
5. 把 zip 拷到另一台 Mac 解压后打开（右键 →「打开」）。

## 第六轮：10 分制与分类（1.8-beta）
1. 大批量实测（约 2000 张，并行 10，1.7.1 曾在这里闪退）：本地筛选跑完不闪退；记录总耗时、平均每张用时、精选／连拍瞬间／可用／淘汰的数量、连拍组数、读取失败数。
2. 整理输出全开：`整理输出/保留/精选|连拍瞬间/连拍NNN_HHMMSS|可用`、`淘汰`，文件名 `两位分数_机型_原名`；数量和报告一致。
3. 抽查 10 组连拍：挑出的连拍瞬间是不是自己也会选的那张（对焦、睁眼、表情）；不合适时调「精彩帧权重」再跑一次，看是否改善。
4. 报告里：给一张打 9 分（XMP 4★、换到精选）、一张打 3 分（1★、换到可用）、一张 ✕；Lightroom 里星级与 分数÷2 向下取整 一致。
5. 载入 1.7.1 生成的旧结果：自动转换，分类和分数合理。
6. AI 细评（会产生费用，本人确认后）：只评单张和每组连拍瞬间；出现 7–10 分；达到 7 分的单张进精选。
7. 韩语界面：两个程序、报告、整理文件夹名（채택／셀렉트／연사 결정적 순간／사용 가능／탈락）。
8. 重新打包 Mac 应用（1.8-beta 是包结构）：自检全部 ✓。
