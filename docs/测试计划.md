# 测试计划

> 状态：1.5-beta 的功能已写完，下面的实机测试**还没有做**，按顺序进行。
> 自动化测试（合成数据）已通过，结果见 `工作记录.md` 第 6 节。

## 第一轮：Sony ARW 跑通（`~/Desktop/TestFIle`，120 组 ARW＋JPG）
1. 照片筛选：演练模式跑一次，看评分是否合理（TestFIle 里不应多出 `.xmp`）。
2. 照片筛选：关掉演练，勾「整理输出」（复制、两层、重命名）跑一次；核对 `整理输出/保留|淘汰/JPEG|RAW/星级_ILCE-1M2_原名`。
3. 报告里：一张改 ✕、一张改 5★、删一张；输出文件夹应跟着变。
4. 再跑一次：输出不重复，手动改的星级还在。
5. 把 `整理输出/保留/RAW` 导入 Lightroom / Capture One，看星级和色标（需要本人操作）。
6. 移动模式：用 `~/Desktop/TestFIle_移动测试`（10 组）。
7. 照片编辑：打开一张 ARW，顶部显示「RAW」；四种自动方案各试一次；四支镜头的暗角各看一下；导出 JPEG 和 16 位 TIFF。

## 第二轮：环境与打包
1. macOS：`安装环境.command --check`、`--recreate` 各跑一次；`启动筛选` / `启动编辑` 能直接打开。
2. Windows 实机：解压测试包，`安装环境.bat` 全新安装（含 winget 安装 Python），再启动两个程序。
3. 镜像切换（`--mirror tuna`）与离线安装（`--download` → `--wheels`）。

## 第三轮：LUT
1. 内置库显示两个分组（Fujifilm GFX 胶片模拟 20、Leica Look 19），全部标为 sRGB，无警告。
2. 抽查 6 个 LUT 的效果：Leica Look BLE / PURE / BW HC，GFX50S CLASSIC CHROME / ASTIA / ACROS。
3. 添加 LUT：选多个 `.cube`（含一个坏文件），好的进「我的 LUT」，坏的给出原因；重名自动加 (2)；移除后列表更新、正在用的 LUT 被取消。
4. 旧编辑记录（改名前保存的）能自动对应到新 LUT。
