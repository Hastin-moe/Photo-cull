## cull.py 的分区（按代码顺序）

1. 数据结构：`Photo` 数据类
2. 读取：HEIF 支持、`open_scaled`、TIFF 结构 RAW 直读（`TiffRaw`）、`load_preview`、`read_exif`、`capture_time`
3. 技术分析：Haar 人脸／眼睛检测、`subject_sharpness`、`reblur`／`focus_blur`、画面签名与 dHash、`analyze`
4. 分组与评分：`group_bursts`（连拍＋同场景）、问题标记代码、`score_local`
5. AI 细评：`PROVIDERS`、`AI_PROMPTS`（三种语言）、各家调用（messages／responses／chat／gemini）、`ai_review`
6. 星级与色标：`assign_ratings`、`label_for`
7. XMP：边车文件合并写入；JPEG 内嵌 XMP（只改 APP1 段）
8. 同步删除：移到废纸篓
9. 整理输出：`organize`（复制／移动、配对文件一起处理、整理记录 `.photo-cull-organize.json`）
10. 报告与结果文件：`load_results`、`summarize`、`write_report`
11. 主流程：`collect`、`process_one`、`main`

## 评分规则（1.7.1）

- 本地分 `local_score`：0–100，本批内锐度百分位 60% ＋ 曝光 30% ＋ 人脸／眼睛 10%。
- 档位 `tier`：`reject`（严重模糊／欠曝／过曝）、`alt`（连拍组里不是最高分）、`candidate`（组内最高分）、`error`。
- 星级 `stars`：淘汰 −1（拒绝）；不开 AI 时入围 3★、备选 2★；AI 给 1–5★（备选最多 2★）。4–5★ 只能由 AI 给。
- 色标：4–5★ 绿、3★ 黄、1★／拒绝 红。
- XMP 写的就是这个 1–5 星（`xmp:Rating`，拒绝为 −1）。

## 整理输出（1.7.1）

```
输出文件夹/
  保留/   JPEG/  RAW/      ← 星级 ≥ 0
  淘汰/   JPEG/  RAW/      ← 拒绝
```
文件名 `星级_机型_原文件名`（拒绝为 `X_`）。

## 数据格式（1.7.1）

`照片文件夹/photo-cull-report/`：
- `results.json`：`Photo` 列表，字段 `path name kind members source time time_text camera lens exposure width height sharp_global sharp_subject sharp_face blur mean_luma clip_high clip_low faces eyes_missing dhash group group_size group_best flags local_score tier ai stars label thumb error manual trashed`。`ai` 为 `{genre, scores{composition, light, subject, moment, technical}, overall, stars(1–5), keep, comment, issues, lang, provider, model}`。没有格式版本号。
- `meta.json`：`src version dry_run no_xmp jpeg_embed xmp_all xmp organized`。
- `results.csv`、`report.html`、`thumbs/`、`ai-cache.json`。

`~/.photo-cull/`：`settings.json`（`settings_version` 3）、`lang.json`、`edits/`（编辑记录，`version` 1）、`luts/`（用户 LUT）、`logs/`、`webview/`、`running-*.json`（运行中的服务登记）。

## HTTP 接口（1.7.1）

筛选：`/api/settings` `/api/status` `/api/choose` `/api/run` `/api/confirm` `/api/cancel` `/api/load` `/api/mark`（`{path, stars}`）`/api/trash` `/api/organize` `/api/reveal` `/api/open_report` `/api/quit`；报告 `/out/<令牌>/…`。

共用：`/api/lang`、`/static/*`、`/open/<app>`、`/shell`、`/ping`。
